## Sobre mim

Sou desenvolvedor de jogos com **Unity e C#**, com projetos voltados a interfaces e componentes reutilizáveis. Minha trajetória também passa por desenvolvimento web com **TypeScript**, algoritmos em **C++**, aplicações em **Python** e projetos de hardware.
